# What Is the Value of an Agency? With Claude Code Handling Ad Uploads, Bidding, and Analysis, Why ...

**公開日: **（取得: 2026-08-26）
出典: https://www.youtube.com/watch?v=UeSxBYL9MV8

## 動画から起こした解説

本動画では、AIを活用した自動化・開発ツールである「Claude Code（クロードコード）」を用いた、業務における実用的な知見の蓄積と活用方法について紹介されています。これを使うことで、過去の業務プロセスや対応履歴を自動で整理・言語化し、必要な時にいつでも過去の知見を瞬時に検索・把握することができます。

具体的な手順と使い方は以下の通りです。まず、これまでのクライアントとのメール、スラック（チャットツール）のやり取り、さらに会議の議事録といった関連データをClaude Codeにすべて読み込ませます。次に、AIに対して「これまでの事例を、時系列まで細かく分かるように説明して」と指示を入力します。するとAIが読み込んだデータを分析し、時系列に沿って整理されたMarkdown（マークダウン：文書を記述するための軽量な記法の一つ）ファイルとして、知見を自動で書き出してくれます。このMarkdownファイルを「Project Folder（プロジェクトフォルダー）」に保存して蓄積しておきます。これにより、後から「あの時なぜこのような対応をしたのか」「これまで何をしてきたか」などを確認したい場合に、Claudeに質問するだけで、詳細な経緯や過去の知見を瞬時に呼び出して把握することができます。

料金や制限について動画内での明確な金額提示はありませんが、大量のやり取りや議事録を読み込ませて時系列のMarkdownファイルとして整理させる際、トークン（AIが一度に処理する最小の文字単位）を非常に多く消費する点に言及されています。

注意点として、AIを用いて出力した知見やMarkdownファイルの所有権が、作業を行った個人と会社のどちらに帰属するのかという、情報の管理・流出に関するリスクが挙げられます。情報漏洩を防ぐために、会社が提供するセキュア（安全性の高い）な環境で使用し、データにアクセスできる人員を案件の参加者に制限するなどの対策が必要です。また、時系列で詳細な記録が残されていたとしても、実際にそのプロジェクトや打ち合わせに同席していない人が見る場合、文字面だけの表面的な理解に留まってしまい、深い背景までは理解できない可能性があるため、共有の限界についても留意する必要があります。
