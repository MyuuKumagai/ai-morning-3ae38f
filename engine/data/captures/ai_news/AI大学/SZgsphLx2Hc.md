# [Weekly AI Tools & News Roundup] New Claude Code Features, Claude Opus 3.5, 3 New Gemini Models, ...

**公開日: 2026-07-26**（取得: 2026-07-28）
出典: https://www.youtube.com/watch?v=SZgsphLx2Hc

## 動画から起こした解説

この動画では、最新のAIモデル「Claude Opus 5」や画像生成AI「Qwen-Image-3.0」をはじめとする、複数の最新AIツールのアップデート情報が紹介されています。これらを利用することで、高度なプログラミング支援や直感的な画像生成・編集、音声対話、業務の自動化などが可能になります。

具体的な使い方として、まず高精度な画像生成AI「Qwen-Image-3.0」の操作手順です。公式AIチャット「Qwen Studio」を開き、フォームにある「＋」ボタンから「画像を作成する」を選びます。モデル選択で「Qwen-Image-3.0」を指定し、チャット経由で指示テキストを送信すれば画像が生成されます。画像をアップロードして編集を指示することも可能です。
次に、作業を自動化する「Claude Cowork」の「Record a skill（操作の録画学習）」機能です。作業中の画面を録画しながら何をしているのかを音声で説明すると、AIがそれを自動で「スキル（繰り返し実行できる操作）」に変換してくれます。
また、業務を支援するGensparkの「SecondBrain（データをまとめて記憶する機能）」では、GmailやSlackなどを接続し、過去のやり取りやドキュメントを記憶させることで、ユーザー個人に最適化された仕事の支援を受けられます。

料金や制限について、Googleの「Gemini 3.6 Flash」や「Qwen-Image-3.0」は無料チャットサービスで誰でも無料で利用可能です。一方、最新AIの「Claude Fable 5」はClaudeのMaxやTeam Premiumといった有料プランの範囲内で、通常の50％の制限付きで利用できます。

注意点として、「Qwen-Image-3.0」が生成する画像内の日本語は、ところどころ日本語がおかしい箇所があるため完全な表現には向いていません。また、Claude Coworkの「Record a skill」機能はWindows版への実装が確認できておらず、Mac環境以外での利用には注意が必要です。
