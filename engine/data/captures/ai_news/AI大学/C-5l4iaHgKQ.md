# Is It Actually That Good? The Complete Guide to the "Kimi K3" AI Model! Performance Rivaling GPT-...

**公開日: 2026-08-01**（取得: 2026-08-02）
出典: https://www.youtube.com/watch?v=C-5l4iaHgKQ

## 動画から起こした解説

この動画では、中国のAIスタートアップであるMoonshot AIが開発した最新のAIモデル「Kimi K3（キミ ケースリー）」が紹介されています。Kimi K3は、2兆8000億ものパラメータ（AIの規模を表す数値）を持ち、100万トークン（テキストのまとまり）という長大なデータを一度に処理できます。画像やグラフの理解、高度な推論、プログラミングに加え、複雑なWebアプリや2D・3Dゲームの自動生成、Webサイトの構築、スライド資料や解説動画の生成など、幅広いタスクを実行できます。

具体的な使い方は、主に公式AIチャット「Kimi」と、デスクトップアプリの「Kimi Work」を介して利用します。「Kimi」をWebサイトで使う手順は次の通りです。
1. Kimiの公式Webサイトを開きます。
2. 画面の左下にあるログインボタンを押します。
3. Googleアカウントや電話番号などでログインします。
ログイン後はすぐにAIチャットが利用でき、日本語で指示を入力して実行させます。画面下部にある「ウェブサイト」「スライド」「シート」「ドキュメント」などの専用ボタンを選択して指示を送ることで、それぞれの生成に特化した機能（プラグイン）を使って簡単に資料やWebページを作ることができます。

もう一つの「Kimi Work」では、モデル設定でKimi K3を選択して指示を行います。このアプリでは「スキル」と呼ばれる専門知識を追加する仕組みが使えます。例えば、動画生成用のスキル「hyperframes（ハイパーフレームズ）」をインストールして指示を出せば、台本に沿った高画質なアニメーション動画を作ることができます。さらに開発者向けには「Kimi API Platform」のほか、AIコードエディタの「Cursor」やAIチャット「Perplexity」でもKimi K3が実装されており、それらのツールから呼び出して使うことができます。

料金については、Webサイトでの基本的なチャット機能は無料ユーザーでも利用可能です。より高度な機能が使える「Kimi Work」のプランは月額19ドルからの有料登録が用意されています。APIの料金は、100万入力トークン（AIが読み込む言葉の単位）あたり3ドル、100万出力トークン（AIが書き出す言葉の単位）あたり15ドルです。

注意点として、以前の中国系モデルにありがちだった「突然中国語になる」「不自然な日本語になる」といった現象はほぼ解消されていますが、完璧ではありません。また、CursorやPerplexityを使って実行する際には、データが米国内のサーバーで処理される仕組みになっている点に留意して利用してください。
